# Blackjack — встроенный терминал

> Мини-игра «Казино Блэкджек», работающая внутри LuminaBooks как отдельная вкладка.
> Игра — консольная программа на Go, LuminaBooks запускает её дочерним процессом и рендерит вывод в `xterm.js`.

---

## 1. Что это

Вкладка **♠ Блэкджек** в хедере открывает встроенный терминал, в котором работает оригинальная консольная игра `blackjack.go`:

- Полноценные правила блэкджека с настраиваемыми колодами, страховкой, сплитами, удвоением и сдачей
- ANSI-цвета мастей (красные/белые)
- Сохранение балансов между сессиями (`blackjack_save.json`)
- Логирование раундов (`blackjack.log`)
- Панель флагов запуска прямо в UI

---

## 2. Требования

- **Go 1.22+** — для сборки бинарника из исходника. Нужен один раз, потом не требуется.
- Готовый бинарник под вашу ОС в `blackjack/` (см. раздел 4).

---

## 3. Как запустить (для конечного пользователя)

1. Установите LuminaBooks.
2. Откройте вкладку **♠ Блэкджек**.
3. Игра запустится автоматически.
